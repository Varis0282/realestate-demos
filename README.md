# Real Estate Website Demos

Five complete, themed demo websites for one fictional builder (Shivalik Buildcon, Indore) — built with Next.js 14 + Tailwind.

- `/` — showcase landing (pick a design)
- `/pillar` Classic Trust · `/skyline` Modern Animated · `/aangan` Warm Homely · `/noir` Dark Premium · `/blueprint` Minimal Editorial
- Each theme: Home, About, Projects, Amenities, Gallery, Contact + free site-visit WhatsApp booking, Hindi/English toggle

**Rebrand for a client:** edit `lib/config.ts` (name, city, phone, WhatsApp, map, projects images).

```bash
npm install
npm run dev
```
